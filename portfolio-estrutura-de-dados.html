Project information

Creation of Data Infrastructure for E-commerce

Step 1: The starting point was using SQL on a PostgreSQL database (via Supabase), simulating AWS by using the S3 service with the same protocols as the Amazon service. This initial approach aimed at gaining some insight into the data through deep exploratory analysis. In this phase, 12 fundamental queries were developed to answer critical business questions from the Customers, Pricing and Sales departments.

Step 2: To simulate market reality, I used Python to automate the extraction of data that, in real systems, is isolated. The extraction used Parquet data, overcoming the limitation of simple manual spreadsheets.

Step 3: This step consisted of creating a DW and Datamarts appropriate to each business area. The modeling was done with dbt (Data Build Tool), where I structured the data into a Medallion architecture using the Google Antigravity IDE, connecting dbt directly to my Postgres Supabase database.
• Silver Layer: Where the data was ingested as-is;
• Bronze Layer: Some aggregations and cleanups were performed. One of the transformations was the creation of a column with line-by-line revenue, which did not exist in the data;
and • Gold Layer: Designed based on the business queries from Step 1. In this layer, data was modeled and refined to be delivered ready for decision-making areas, serving as the company's "single source of truth".

Step 4: Here is the coolest part! The final and most innovative step was the implementation of an AI Agent (Agentic AI). This solution was integrated so directors and managers could query all KPIs and analyses from the gold layer directly from their phones, using natural language to obtain real-time insights, with each area having access to the data processed in the gold layer.
